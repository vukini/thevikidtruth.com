# Unity Game Programming

[Unity](https://unity3d.com/) is a game programming environment that you can use to build Games and other 3D virtual environments.
I first came across unity while talking to some serious VR programmers in Orlando, USA. The kind of things they were building
really fascinated me and I decided that I must try out this technology for my self.

So far, I have got my Oculus Rift and installed Unity on my Windows 10 system. May the fun begin!

### The plain idea

[Unity](https://unity.com/) is a **game engine**: a complete toolkit for building games and other interactive 3D (and 2D) experiences, physics, graphics, sound, input and a visual scene editor, all in one place, so you are not writing a renderer from scratch. You arrange objects in a scene, attach behaviour to them as **C# scripts**, and press play. It is one of the most widely used engines in the world, behind a huge share of mobile games and much VR/AR work.

### Why it matters

Before engines like Unity, making even a simple game meant months of low-level graphics and maths before you could draw a single moving box. Unity collapses that barrier: a beginner can have something interactive running in an afternoon, while professionals ship commercial titles with the same tool. For VR in particular, as my note recalls with the Oculus Rift, Unity became the default way in.

### An everyday analogy

Building a game without an engine is like making a film by first inventing the camera, the film stock and the projector. Unity hands you a fully equipped film studio, cameras, lighting rigs, a sound stage, so you can get straight to telling the story (making the game) instead of reinventing the equipment.

### A 2026 note

Two big changes since I wrote the intro above. First, **Windows 10 is now end-of-life** (support ended October 2025), so a current setup would be Windows 11, macOS or Linux. Second, and more important for anyone choosing an engine today: in 2023 Unity announced a controversial per-install "Runtime Fee" that caused a large backlash and pushed many developers toward alternatives, chiefly **Godot** (free, fully open-source) and **Unreal Engine**. Unity later walked the fee back and changed leadership, but it is worth knowing the landscape is more competitive now. For a free-software-minded learner, Godot is very much worth a look alongside Unity. The Oculus Rift, meanwhile, has been succeeded by the Meta Quest line.
