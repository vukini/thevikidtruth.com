# Unity Game Programming

[Unity](https://unity3d.com/) is a game programming environment that you can use to build Games and other 3D virtual environments.
I first came across unity while talking to some serious VR programmers in Orlando, USA. The kind of things they were building
really fascinated me and I decided that I must try out this technology for my self.

So far, I have got my Oculus Rift and installed Unity on my Windows 10 system. May the fun begin!
