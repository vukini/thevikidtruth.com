# Digraphs

[Back to The Compiler](thecompiler.md)

Not some punctuation marks are not available on all keyboards. In this case we
can use the following Digraphs in our source files.

```
<:   is translated into [

:>   is translated into ]

<%   is translated into \{

%>   is translated into \}

%:   is translated into \#

%:%: is translated into \##
```
