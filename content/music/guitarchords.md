# Guitar Chords

[Guitar](guitar.md) | [Open Chords](openchords1.md) | [Triads](triads.md) | [Learn the Fretboard](learnthefretboard.md) | [Chord Progressions](chordprogressions.md)

## The core idea in plain words

A chord is **three or more notes sounded together**. On guitar, a chord shape is simply a way of holding down strings so that every string you strum plays one of those notes.

The recipe for the basic chords is short:

- **Major chord** = root + major 3rd + perfect 5th (scale degrees 1–3–5). Bright, settled.
- **Minor chord** = root + minor 3rd + perfect 5th (1–♭3–5). Darker, sadder.
- **Dominant 7th** = major chord + minor 7th (1–3–5–♭7). Tense; wants to resolve.
- **Major 7th** = major chord + major 7th (1–3–5–7). Dreamy, jazzy.
- **Minor 7th** = minor chord + minor 7th (1–♭3–5–♭7). Mellow.
- **sus2 / sus4** = replace the 3rd with the 2nd or 4th. Neither major nor minor — open and floating.

If you know which notes are in a chord, you can check any shape yourself: name the note on each string and see if it's in the recipe. See [Triads](triads.md) and [The Musical Alphabet](musicalalphabet.md) for where the recipe comes from.

## An analogy: a recipe, not a photograph

A chord name is a recipe ("C, E and G"), not a photograph of one hand position. The open C shape, a barre C at the 8th fret and a three-string triad at the 5th fret are all the same dish cooked in different kitchens. Learn the shapes, but also learn the ingredients — that is what frees you from the chord chart.

## How to read the shapes

Strings are listed from the low (thick) E to the high (thin) E: **E A D G B E**. Each number is the fret to press; `0` means an open string; `x` means don't play it. Next to each shape are the notes it actually sounds, low to high — every one checked against the recipe.

## The essential open chords

### Major

| Chord | Shape (E A D G B E) | Notes sounded | Chord tones |
|---|---|---|---|
| C | x 3 2 0 1 0 | C E G C E | C E G |
| A | x 0 2 2 2 0 | A E A C♯ E | A C♯ E |
| G | 3 2 0 0 0 3 | G B D G B G | G B D |
| E | 0 2 2 1 0 0 | E B E G♯ B E | E G♯ B |
| D | x x 0 2 3 2 | D A D F♯ | D F♯ A |

These five are the "CAGED" shapes. Every major chord anywhere on the neck is one of them, moved up.

### Minor

| Chord | Shape | Notes sounded | Chord tones |
|---|---|---|---|
| Am | x 0 2 2 1 0 | A E A C E | A C E |
| Em | 0 2 2 0 0 0 | E B E G B E | E G B |
| Dm | x x 0 2 3 1 | D A D F | D F A |

### Seventh chords

| Chord | Shape | Notes sounded | Chord tones |
|---|---|---|---|
| G7 | 3 2 0 0 0 1 | G B D G B F | G B D F |
| C7 | x 3 2 3 1 0 | C E B♭ C E | C E G B♭ (5th omitted) |
| D7 | x x 0 2 1 2 | D A C F♯ | D F♯ A C |
| E7 | 0 2 0 1 0 0 | E B D G♯ B E | E G♯ B D |
| A7 | x 0 2 0 2 0 | A E G C♯ E | A C♯ E G |
| Cmaj7 | x 3 2 0 0 0 | C E G B E | C E G B |
| Fmaj7 | x x 3 2 1 0 | F A C E | F A C E |
| Am7 | x 0 2 0 1 0 | A E G C E | A C E G |
| Em7 | 0 2 0 0 0 0 | E B D G B E | E G B D |

### Suspended

| Chord | Shape | Notes sounded | Chord tones |
|---|---|---|---|
| Dsus2 | x x 0 2 3 0 | D A D E | D E A |
| Dsus4 | x x 0 2 3 3 | D A D G | D G A |
| Asus2 | x 0 2 2 0 0 | A E A B E | A B E |
| Asus4 | x 0 2 2 3 0 | A E A D E | A D E |

### Barre chords (movable)

| Chord | Shape | Notes sounded | Chord tones |
|---|---|---|---|
| F (E-shape, 1st fret) | 1 3 3 2 1 1 | F C F A C F | F A C |
| Fm (Em-shape, 1st fret) | 1 3 3 1 1 1 | F C F A♭ C F | F A♭ C |
| B♭ (A-shape, 1st fret) | x 1 3 3 3 1 | B♭ F B♭ D F | B♭ D F |
| Bm (Am-shape, 2nd fret) | x 2 4 4 3 2 | B F♯ B D F♯ | B D F♯ |

Slide an E-shape barre up the neck and the root (on the low E string) names the chord: 3rd fret = G, 5th = A, 8th = C. Slide an A-shape barre and the root is on the A string: 3rd fret = C, 5th = D, 7th = E.

## A worked example: checking a shape yourself

Is `x 3 2 0 1 0` really a C major? Name each note:

- A string, 3rd fret: A → A♯ → B → **C**
- D string, 2nd fret: D → D♯ → **E**
- G string, open: **G**
- B string, 1st fret: **C**
- high E, open: **E**

Notes: C, E, G, C, E. The recipe for C major is C–E–G. Every note is in the recipe, and the lowest note is the root, C. Confirmed.

Now try `x 0 2 2 1 0`, which most books call Am: A, E (D string 2nd fret), A (G string 2nd fret), C (B string 1st fret), E. A–C–E: root, minor 3rd, 5th. Confirmed — and notice that moving one finger (the B string from fret 2 to fret 1) is all that separates A major from A minor. That one fret is the major 3rd becoming a minor 3rd.

## Practice: the one-four-five

In any key the I, IV and V chords cover thousands of songs. In G: **G – C – D**. In C: **C – F – G**. In A: **A – D – E**. In E: **E – A – B** (use the Bm-shape barre without the minor: `x 2 4 4 4 2`). Add the vi chord (Em in G, Am in C) and you have the four-chord progression. More on the [Chord Progressions](chordprogressions.md) page, and try them on the [Songs to Learn](songs2learn.md).

## Common misconceptions

- **"You must strum all six strings."** The `x` matters. Strumming the low E on a C chord adds an E in the bass — not wrong, but muddy.
- **"Barre chords are for later."** Start a partial F (`x x 3 2 1 1`) in week two; strength comes from doing it.
- **"Seventh chords are a different family."** They're the same triad with one extra note.
- **"Sharp and flat names are interchangeable."** Sound-wise yes; spelling-wise the key decides (F major has B♭, not A♯).
