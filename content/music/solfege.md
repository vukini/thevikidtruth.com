# Solfege

```
 do di re ri mi fa fi so si la li ti do

 do ti te la le so se fa me me re ra do
```

```
 do di/ra re ri/me mi/fe fa fi/se so si/le l li/te ti/di do
```

```
di <-- do --> di

ra <-- re --> ri

me <-- mi

fe <-- fa --> fi

se <-- so --> si

te <-- ti
```
