# Esperanto: Bonvenon (Laŭra kaj Petro Malkovras Esperanton)

Copy each block. Read it, then copy from memory. Check spellings. Use google translate or equivalent if you don't understand anything.

```
Bonan tagon! Mia nomo estas Laŭra.
Mi estas la prezidantino de la Esperanto-klubo Bonvenon.
```

```
Saluton! Mi estas Petro, kaj Laŭra estas mia fratino,
kaj ni du kunfondis la klubon
Ni estas gefratoj.
```

```
Mi loĝas kun nia patrino kaj al mi plaĉas videoludi kaj rokmuziko.

Mi vivas kun nia patro, mi ŝatas legi kaj danci.
```

```
Ses monatojn antaŭe ni sciis nenion pri Esperanto, kaj nun ni fondis klubon!

Ni volas rakonti al vi kiel ni malkovris ĉi tiun lingvon.
```
