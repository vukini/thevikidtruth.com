# Bonvenon - Laura kaj Petro malkovras Esperanton

Copy each block. Read it, then copy from memory. Check spellings. Use google translate or equivalent if you don't understand anything.

```
Bonan tagon! Mia nomo estas Laura.
Mi estas la prezidantino de la Esperanto-klubo Bonvenon.
```

```
Saluton! Mi estas Petro, kaj Lauxra estas mia fratino,
kaj ni du kunfondis la klubon
Ni estas gefratoj.
```

```
Mi logxas kun nia patrino kaj al mi placxas videoludi kaj rokmuziko.

Mi vivas kun nia patro, mi sxatas legi kaj danci.
```

```
Ses monatojn antauxe ni sciis nenion pri Esperanto, kaj nun ni fondis klubon!

Ni volas rakonti al vi kiel ni malkovris cxi tiun lingvon.
```
