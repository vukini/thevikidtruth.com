# Esperanto: Everyday Phrases

Everyday phrases by situation. Practise them on the [Esperanto practice page](/languages/esperanto-practice/?deck=phrases) (Phrases deck).

### Greetings and politeness

| Esperanto | English | Note |
|---|---|---|
| Bonan matenon! | Good morning! | accusative -n: a wish |
| Bonan tagon! | Good day! |  |
| Bonan vesperon! | Good evening! |  |
| Bonan nokton! | Good night! |  |
| Kiel vi fartas? | How are you? |  |
| Mi fartas bone, dankon. | I'm fine, thank you. |  |
| Kaj vi? | And you? |  |
| Estas plezuro koni vin. | Pleased to meet you. |  |
| Ĝis morgaŭ! | See you tomorrow! |  |
| Ĝis baldaŭ! | See you soon! |  |
| Bonan tagon al vi! | Have a nice day! |  |
| Koran dankon! | Heartfelt thanks! |  |
| Dankon pro via helpo. | Thank you for your help. |  |
| Ne dankinde. | You're welcome; don't mention it. |  |
| Mi bedaŭras. | I'm sorry. |  |
| Bonvenon! | Welcome! |  |

### Getting to know someone

| Esperanto | English | Note |
|---|---|---|
| Kiel vi nomiĝas? | What's your name? |  |
| Mi nomiĝas… | My name is… |  |
| Kio estas via nomo? | What is your name? |  |
| De kie vi venas? | Where are you from? |  |
| Mi venas el… | I come from… |  |
| Kie vi loĝas? | Where do you live? |  |
| Mi loĝas en Dubajo. | I live in Dubai. |  |
| Kio estas via profesio? | What is your job? |  |
| Kiom aĝa vi estas? | How old are you? |  |
| Mi estas tridekjara. | I'm thirty years old. |  |
| Ĉu vi parolas Esperanton? | Do you speak Esperanto? | ĉu makes a yes/no question |
| Ĉu vi parolas la anglan? | Do you speak English? |  |
| Mi parolas iomete. | I speak a little. |  |
| Mi lernas Esperanton. | I'm learning Esperanto. |  |
| De kiam vi parolas Esperanton? | Since when have you spoken Esperanto? |  |

### Getting around

| Esperanto | English | Note |
|---|---|---|
| Kie estas la necesejo? | Where is the toilet? |  |
| Kie estas la stacidomo? | Where is the station? |  |
| Kiel mi iru al…? | How do I get to…? | -u for "should I" |
| Ĉu estas malproksime? | Is it far? |  |
| Estas tre proksime. | It's very close. |  |
| Iru rekte. | Go straight on. |  |
| Turnu maldekstren. | Turn left. | -n shows direction |
| Turnu dekstren. | Turn right. |  |
| Unu bileton al Parizo, mi petas. | One ticket to Paris, please. |  |
| Je kioma horo foriras la trajno? | What time does the train leave? |  |
| Kioma horo estas? | What time is it? |  |
| Estas la tria. | It's three o'clock. |  |
| Mi perdiĝis. | I'm lost. |  |

### Shopping and eating

| Mi nur rigardas. | I'm just looking. |  |
| Mi ŝatus… | I would like… |  |
| Ĉu vi havas…? | Do you have…? |  |
| La kalkulon, mi petas. | The bill, please. |  |
| Tablon por du, mi petas. | A table for two, please. |  |
| Kion vi rekomendas? | What do you recommend? |  |
| Mi estas vegetarano. | I'm vegetarian. |  |
| Bonan apetiton! | Enjoy your meal! |  |
| Je via sano! | Cheers! To your health! |  |
| Estas bongusta. | It's tasty. |  |
| Ĉu mi povas pagi per karto? | Can I pay by card? |  |
