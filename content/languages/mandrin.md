# Mandarin: Start Here

Mandarin is next on my list. This page is my starting point.

## 1. Writing and pronunciation

Mandarin is written in **Chinese characters** (汉字 *hànzì*). Each character is one syllable and usually one meaning. Learners read with **pinyin**, the official romanisation.

Every syllable has a **tone**, and the tone changes the word:

| Tone | Mark | Shape | Example |
|---|---|---|---|
| 1 | mā | high and level | 妈 mother |
| 2 | má | rising, like a question | 麻 hemp |
| 3 | mǎ | dips, then rises | 马 horse |
| 4 | mà | sharp fall | 骂 to scold |
| neutral | ma | light, short | 吗 question particle |

Pinyin traps: **x** ≈ *sh* (xiè), **q** ≈ *ch* (qī), **zh** ≈ *j* (zhōng), **c** ≈ *ts* (cài).

## 2. Core grammar

- **Word order is subject–verb–object**, like English: *Wǒ hē chá.* (我喝茶) I drink tea.
- **Verbs never change** for person or tense; time words do the work: *Wǒ míngtiān qù.* I'll go tomorrow. **了 le** marks a completed action: *Wǒ chī le.* I've eaten.
- **No plurals**, but counting needs a **measure word**: *yí ge rén* (一个人) one person, *sān běn shū* (三本书) three books.
- **"To be"** is **是 shì** for nouns: *Wǒ shì VikiD.* Adjectives use **很 hěn** instead: *Tā hěn gāo.* He is tall.
- **Questions**: add **吗 ma** at the end: *Nǐ hǎo ma?* Are you well?
- **Negation**: **不 bù** (*wǒ bú qù*, I'm not going); **没 méi** for "have not" (*wǒ méi yǒu*, I don't have).

## 3. Essential phrases

| Chinese | Pinyin | English |
|---|---|---|
| 你好 | nǐ hǎo | Hello |
| 谢谢 | xièxie | Thank you |
| 不客气 | bú kèqi | You're welcome |
| 对不起 | duìbuqǐ | Sorry |
| 我叫 ... | wǒ jiào ... | My name is ... |
| 我听不懂 | wǒ tīng bù dǒng | I don't understand |
| 多少钱? | duōshao qián? | How much is it? |
| 是 / 不是 | shì / bú shì | Yes / No (it is / it isn't) |
| 再见 | zàijiàn | Goodbye |
