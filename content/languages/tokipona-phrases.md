# Toki Pona: Everyday Phrases

Everyday phrases by situation. Practise them on the [Toki Pona practice page](/languages/tokipona-practice/?deck=phrases) (Phrases deck).

### Greetings

| Toki Pona | English | Note |
|---|---|---|
| toki! | hello! |  |
| toki pona! | hello! (literally good talk) |  |
| mi pona. | I'm well. |  |
| sina pona ala pona? | are you well? | X ala X makes a yes/no question |
| pona! | thanks! good! |  |
| pona tawa sina. | thanks to you; good to you |  |
| tawa pona! | goodbye (to someone leaving), have a good journey |  |
| awen pona! | goodbye (to someone staying) |  |
| lape pona! | sleep well! |  |
| moku pona! | enjoy your meal! |  |
| kama pona! | welcome! |  |
| mi pilin pona. | I feel good. |  |
| mi pilin ike. | I feel bad. |  |
| mi pakala. | I'm sorry; my mistake. |  |
| pakala! | damn! oops! |  |
| ike a! | oh no! |  |

### Getting to know someone

| Toki Pona | English | Note |
|---|---|---|
| nimi sina li seme? | what's your name? |  |
| nimi mi li Wiki. | my name is Wiki. | names are proper adjectives: jan Wiki |
| mi jan Wiki. | I'm Wiki. |  |
| sina tan ma seme? | where are you from? |  |
| mi tan ma ni. | I'm from this country. |  |
| sina lon ma seme? | where are you? |  |
| mi lon tomo. | I'm at home. |  |
| sina pali e seme? | what do you do? |  |
| sina sona ala sona toki pona? | do you know Toki Pona? |  |
| mi sona lili e toki pona. | I know a little Toki Pona. |  |
| mi kama sona e toki pona. | I'm learning Toki Pona. | kama sona = come to know |
| toki pona li pona tawa mi. | I like Toki Pona. | X li pona tawa mi = I like X |

### Understanding

|---|---|---|

| nimi ni li seme? | what does this word mean? |  |

| ala. | no. |  |
