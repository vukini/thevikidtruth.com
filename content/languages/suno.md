#### Suno

[Wikipedia: Suno](https://eo.m.wikipedia.org/wiki/Suno)

```
La Suno (latine Sol, greke Helios) estas la nura stelo de Sunsistemo.
```

The Sun (Latin Sol, Greek Helios) is the only star in the Solar System.

```
La restaj objektoj de tiu sistemo rondiras ĉirkaŭ Suno aŭ iu objekto
rondiranta Sunon.
```

The remaining objects in this system revolve around the Sun or any object orbiting the Sun.

```
Ĝi estas mezgranda stelo de spektroklaso G2V, flava nano.
```

It is a medium-sized star in the G2V spectrum, a yellow dwarf.

```
Kiel la aliaj steloj en la universo, la Suno estas grandega globo de plasmo.
```

Like the other stars in the universe, the Sun is a huge plasma globe.

```
La Tero estas nur je proksimume 150.000.000 km de la Suno.
```
The Earth is only about 150,000,000 km from the Sun.

```
La stela sistemo plej proksima al la Suno estas Alfa Centaŭro.
```
The stellar system closest to the Sun is Alpha Centauri.

```
La lumo de la steloj de tiu sistemo bezonas 4,35 jarojn por atingi la Teron.
```
The light from the stars of that system takes 4.35 years to reach Earth.

```
La lumo de la Suno bezonas nur 8,3 minutojn por atingi nin.
```
The light from the Sun takes only 8.3 minutes to reach us.
