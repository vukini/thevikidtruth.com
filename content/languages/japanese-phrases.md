# Japanese: Everyday Phrases

Everyday phrases by situation. Practise them on the [Japanese practice page](/languages/japanese-practice/?deck=phrases) (Phrases deck).

### Greetings and politeness

| Japanese | Romaji | English | Note |
|---|---|---|---|

| おやすみなさい | oyasumi nasai | Good night. |  |

### Getting to know someone

| Japanese | Romaji | English | Note |
|---|---|---|---|
| お名前は何ですか | o-namae wa nan desu ka | What's your name? |  |
| 私は〜です | watashi wa ~ desu | I am ~. |  |
| 〜と申します | ~ to mōshimasu | My name is ~. (humble) |  |
| どちらから来ましたか | dochira kara kimashita ka | Where are you from? |  |
| 〜から来ました | ~ kara kimashita | I came from ~. |  |
| ドバイに住んでいます | Dobai ni sunde imasu | I live in Dubai. |  |
| お仕事は何ですか | o-shigoto wa nan desu ka | What's your job? |  |
| 英語を話せますか | eigo o hanasemasu ka | Can you speak English? |  |
| 日本語を少し話します | nihongo o sukoshi hanashimasu | I speak a little Japanese. |  |
| 日本語を勉強しています | nihongo o benkyō shite imasu | I'm studying Japanese. |  |

| 〜はどういう意味ですか | ~ wa dō iu imi desu ka | What does ~ mean? |  |
