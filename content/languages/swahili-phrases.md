# Swahili: Everyday Phrases

Everyday phrases by situation. Practise them on the [Swahili practice page](/languages/swahili-practice/?deck=phrases) (Phrases deck).

### Greetings and politeness

| Swahili | English | Note |
|---|---|---|
| Habari gani? | What's the news? (how are you?) |  |
| Habari za asubuhi? | Good morning (how's the morning?) |  |
| Habari za jioni? | Good evening |  |
| Nzuri. | Fine, good. | the usual reply to habari |
| Salama. | Fine, peaceful. |  |
| Mambo? | What's up? | reply: poa |
| Poa. | Cool, fine. |  |
| Hamjambo? | How are you all? | reply: hatujambo |
| Hatujambo. | We are fine. |  |
| Karibu sana. | You're very welcome. |  |
| Asante sana. | Thank you very much. |  |
| Si kitu. | It's nothing; you're welcome. |  |
| Pole. | Sorry (sympathy). | for someone's trouble, not an apology |
| Pole sana. | I'm so sorry for you. |  |
| Tutaonana. | See you. |  |
| Tuonane kesho. | Let's see each other tomorrow. |  |
| Lala salama. | Sleep well. |  |
| Siku njema. | Have a good day. |  |
| Safari njema. | Have a good journey. |  |

### Getting to know someone

| Swahili | English | Note |
|---|---|---|
| Jina lako nani? | What's your name? |  |
| Jina langu ni… | My name is… |  |
| Unatoka wapi? | Where are you from? |  |
| Ninatoka… | I come from… |  |
| Unaishi wapi? | Where do you live? |  |
| Ninaishi Dubai. | I live in Dubai. |  |
| Unafanya kazi gani? | What work do you do? |  |
| Una miaka mingapi? | How old are you? |  |
| Nina miaka thelathini. | I'm thirty years old. |  |
| Unasema Kiingereza? | Do you speak English? |  |
| Ninasema Kiswahili kidogo. | I speak a little Swahili. |  |
| Ninajifunza Kiswahili. | I'm learning Swahili. |  |

### Understanding

| Swahili | English | Note |
|---|---|---|
| Sielewi. | I don't understand. |  |
| Rudia, tafadhali. | Repeat, please. |  |
| Sema polepole, tafadhali. | Speak slowly, please. |  |
| Maana yake nini? | What does it mean? |  |
| Unasemaje … kwa Kiswahili? | How do you say … in Swahili? |  |
| Sijui. | I don't know. |  |
| Nadhani hivyo. | I think so. |  |
| Bila shaka. | Without doubt, of course. |  |
| Kweli. | True, really. |  |
| Ni kweli. | It's true. |  |
| Hakuna matata. | No problem. |  |
| Hakuna shida. | No problem. |  |
| Haidhuru. | It doesn't matter. |  |
| Inategemea. | It depends. |  |
| Hongera! | Congratulations! |  |

### Getting around

| Swahili | English | Note |
|---|---|---|
| Choo kiko wapi? | Where is the toilet? |  |
| Kituo cha basi kiko wapi? | Where is the bus stop? |  |
| Nitafikaje…? | How will I get to…? |  |
| Ni mbali? | Is it far? |  |
| Ni karibu. | It's near. |  |
| Nenda moja kwa moja. | Go straight on. |  |
| Geuka kushoto. | Turn left. |  |
| Geuka kulia. | Turn right. |  |
| Simama hapa. | Stop here. |  |
| Saa ngapi? | What time is it? |  |
| Ni saa tatu asubuhi. | It's nine in the morning. | hours are counted from 6 a.m., so saa tatu = 9 a.m. |
| Nimepotea. | I'm lost. |  |

### Shopping and eating

| Swahili | English | Note |
|---|---|---|
| Bei gani? | What's the price? |  |
| Ni shilingi ngapi? | How many shillings is it? |  |
| Ni ghali sana. | It's very expensive. |  |
| Punguza bei. | Lower the price. |  |
| Ninaangalia tu. | I'm just looking. |  |
| Nataka… | I want… |  |
| Ninaomba… | May I have… | polite request |
| Una…? | Do you have…? |  |
| Lete bili, tafadhali. | Bring the bill, please. |  |
| Chakula ni kitamu. | The food is tasty. |  |
| Karibu chakula. | Come and eat with us. |  |
| Nimeshiba. | I'm full. |  |
