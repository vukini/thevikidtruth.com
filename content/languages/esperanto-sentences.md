# Esperanto: Example Sentences

Example sentences, roughly from simple to intermediate, each with a translation and, where useful, a one-line grammar note. Practise them on the [Esperanto practice page](/languages/esperanto-practice/?deck=sentences) (Sentences deck).

| Esperanto | English | Note |
|---|---|---|
| Mi estas studento. | I am a student. |  |
| Ŝi estas hejme. | She is at home. | hejme = at home (adverb) |
| La kafo estas varma. | The coffee is hot. |  |
| Mi havas du fratojn. | I have two brothers. | -j plural, -n object |
| Mi ŝatas ĉokoladon. | I like chocolate. | the object takes -n |
| Ni loĝas apud la maro. | We live by the sea. |  |
| Hodiaŭ estas varme. | It's warm today. | no subject for weather |
| Morgaŭ pluvos. | It will rain tomorrow. | -os = future |
| Dimanĉe mi iras al la plaĝo. | On Sundays I go to the beach. | dimanĉe = on Sunday(s) |
| La trajno foriras je la oka. | The train leaves at eight. | je = at (time) |
| Ĉu vi povas helpi min? | Can you help me? |  |
| Mi ne povas veni ĉi-vespere. | I can't come this evening. |  |
| Mi volas lerni Esperanton. | I want to learn Esperanto. |  |
| Mi devas labori morgaŭ. | I have to work tomorrow. |  |
| Mi nun legas libron. | I'm reading a book now. | -as covers both I read and I am reading |
| Kion vi faras? | What are you doing? |  |
| Mia fratino estas pli alta ol mi. | My sister is taller than me. | pli … ol |
| Tio estas la plej bona restoracio en la urbo. | That's the best restaurant in town. | la plej = the most |
| Estas multaj homoj sur la strato. | There are many people in the street. | estas = there is / are |
| Estas nenio en la fridujo. | There's nothing in the fridge. | only one negative word |
| Mi neniam trinkas kafon vespere. | I never drink coffee in the evening. |  |
| Hieraŭ mi manĝis picon. | Yesterday I ate pizza. | -is = past |
| Ni iris al la kinejo sabate. | We went to the cinema on Saturday. |  |
| Kiam mi estis infano, mi loĝis en la kamparo. | When I was a child, I lived in the countryside. |  |
| Mi jam vizitis Francion dufoje. | I've already visited France twice. | -foje = times |
| Ĉu vi jam manĝis? | Have you eaten yet? |  |
| Mi loĝas ĉi tie jam de tri jaroj. | I've been living here for three years. | jam de + present |
| Mi donis ĝin al mia patrino. | I gave it to my mother. |  |
| Diru al mi! | Tell me! | -u = command |
| Ne diru tion al li. | Don't tell him that. |  |
| Mi esperas, ke vi fartas bone. | I hope you're well. |  |
| Mi volas, ke vi venu. | I want you to come. | -u after a wish |
| Kiam vi alvenos, telefonu al mi. | When you arrive, phone me. | future -os after kiam |
| Se mi havos tempon, mi venos. | If I have time, I'll come. | future in both halves |
| Se mi havus monon, mi vojaĝus pli. | If I had money, I would travel more. | -us = conditional |
| Mia kapo doloras. | My head hurts. |  |
| Oni parolas Esperanton ĉi tie. | Esperanto is spoken here. | oni = one, people |
| Mi ĵus alvenis. | I've just arrived. | ĵus = just now |
| Mi provos denove. | I'll try again. |  |
| La plej grava afero estas provi. | The most important thing is to try. |  |
| Ĉu ĝenas vin, se mi malfermas la fenestron? | Does it bother you if I open the window? |  |
| Estus pli bone atendi. | It would be better to wait. |  |
| Ni tre amuziĝis. | We had a lot of fun. | -iĝ- = to become, get |
| Fine mi finis la laboron. | Finally I finished the work. |  |
| Mi lernas por kompreni, ne por ekzameno. | I learn to understand, not for an exam. | por + infinitive |
| La libro estas skribita de mia amiko. | The book is written by my friend. | -it- = passive past participle |
| La parolanto estas mia instruisto. | The speaker is my teacher. | -ant- = the one doing |
| Mi ne sciis, ke vi parolas la francan. | I didn't know you speak French. | reported speech keeps the original tense |
| Ju pli mi praktikas, des pli bone mi parolas. | The more I practise, the better I speak. | ju … des … |
| Mi iris en la domon. | I went into the house. | en + -n = into |
| Mi estis en la domo. | I was in the house. | en without -n = location |
| La malsanulo resaniĝis. | The sick person recovered. | -ul- = person |
| Ili estas geamikoj. | They are friends (men and women). | ge- for mixed groups |
