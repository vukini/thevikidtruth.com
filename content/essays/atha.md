# Atha

### अथ योगानुशासनम्॥१॥

```
Atha yogānuśāsanam.||1||
```

Here begins the instruction of yoga

### योगश्चित्तवृत्तिनिरोधः॥२॥

```
Yogaścittavṛttinirodhaḥ||2||.
```

Yoga is the suppression of the modifications of mind.

- atha - now
- anuśāsanam - instruction
- nirodhaḥ - suppression
- vṛtti - modifications
- citta - mind
