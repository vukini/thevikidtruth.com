# How to Memorize Anything

### by Aditi Singhal and Sudhir Singhal

### About the book

*How to Memorize Anything* by Aditi Singhal and Sudhir Singhal is a practical guide to memory techniques. It teaches classic methods, the memory palace (method of loci), association, visualisation, number and name systems, and applies them to everyday tasks like remembering names, facts, speeches and study material. It sits alongside my interest in memory systems (see [The Memory Chalet](thememorychalet.md) for a very different, literary take on memory).
