### About the book

*The CS Detective* by Jeremy Kubica (2016) teaches computer-science algorithms through a hard-boiled detective story. Set in a noir world, it follows a detective who solves cases using search algorithms, linear and binary search, breadth- and depth-first search, and more, so that readers absorb how the algorithms work and when to use them without the usual textbook formality. A fun, beginner-friendly introduction to [algorithms](algorithms.md).
